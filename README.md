# GitHub Pages Starter (Jekyll + minima)

This repository is ready to publish on GitHub Pages.

## Quick publish
1. Create a **public** repo named `YOURUSERNAME.github.io` (replace with your GitHub username).
2. Upload these files to the repo.
3. Go to **Settings → Pages** and ensure "Deploy from a branch" is selected with branch `main` and folder `/ (root)`.
4. Your site will be live at `https://YOURUSERNAME.github.io`.

## Add a new post
- Add a file under `/_posts/` named `YYYY-MM-DD-title.md`
- Include the front matter (see example in the welcome post).

## Customize
- Edit `_config.yml` for title, description, social links, and analytics.
- Add more pages like `teaching.md` or `projects.md` and list them in `header_pages` in `_config.yml`.
- Add custom CSS in `assets/css/custom.css`.
